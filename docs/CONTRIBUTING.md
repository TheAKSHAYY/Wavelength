# Contributing

## Welcome

Contributions to Wavelength are welcome if they improve maintainability, product clarity, architecture quality, or the user experience.

## Before You Start

- read the project context and architecture docs
- understand the backend proxy pattern
- check the current environment configuration
- confirm whether the task is a documentation change or a behavior change

## Contribution Expectations

- keep code changes small and intentional
- preserve the modular structure of the project
- do not commit real API keys or secrets
- document any new environment variables
- update docs when behavior, prompts, or contracts change

## Coding Philosophy

- prefer simple and explicit code
- keep services and modules focused
- avoid unnecessary frameworks or complexity
- maintain consistent UI and state patterns

## Review Checklist

Before finalizing a change, confirm:

- the app still builds locally
- the backend still starts without port conflicts
- new environment variables are added to the docs
- security risks were considered
- AI output parsing logic still works
